# 公众号文章雷区 v1.1

## 内容雷区

1. README 逐条翻译
2. 20 个功能写 20 节
3. 只讲优点，不讲边界
4. 只看 Abstract 写论文解读
5. benchmark 不说明是谁测的
6. 项目 README 自述当成独立事实
7. 没亲测却说“实测”
8. 把预印本写成正式发表
9. 把第三方项目写成官方 Skill
10. 把“可选能力”写成“默认能力”

## 风格雷区

11. 每篇都用“最近看到一个……”
12. 每篇都“写在最后”
13. 每篇都固定信息表格
14. 每篇都强制“点赞在看”
15. 一级标题太大
16. 二级标题与一级同号
17. 标题 emoji 过多
18. 每段大量加粗
19. 句子全部一个长度
20. 公文腔 / 翻译腔

## 标题雷区

21. 数据无来源
22. 标题和正文不一致
23. 故意隐藏关键信息
24. 虚假的紧迫感
25. “神作 / 王炸 / 逆天 / 碾压 / 史上最强”
26. 只靠 Star 数而没有内容价值

## AIGC 雷区

27. 套路化的“三段式正确废话”
28. 一节只有两句话
29. 结尾重复全文
30. 观点像百科总结，没有作者判断
31. 机械拼接多个来源
32. 大量引用原文而没有新增解释
