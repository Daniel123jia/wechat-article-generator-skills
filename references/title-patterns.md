# 标题模式参考库

公众号文章的标题决定了打开率。以下是 11 种经过实战检验的标题模式,根据素材特点选择。

---

## 模式 1:数据震撼型

**适用:** Star 数惊人、增长迅速、用户量大、金额巨大

### 公式
```
{震撼数据}！{主体}:{一句话价值}
```

### 实例
- `57.5k Star！5M+ 开发者选择的开源 AI 编程助手 Cline`
- `融资 50 亿!这家国产芯片公司,正在改写格局`
- `单日下载 100 万次!这个 App 凭什么三天屠榜`

### 何时用
- 数据本身就是新闻
- 数据有"故事"(最快、最大、首次)

---

## 模式 2:对比落差型

**适用:** 解决一个常见痛点,有"前后对比"叙事

### 公式
```
{常见痛点描述},{主体}{解决方案}
```

### 实例
- `告别生成的 UI 千篇一律!awesome-design-md:一份 Markdown 让 AI 模仿任意品牌`
- `78k Star 神作!一个 65 行的 CLAUDE.md 文件,解决了 AI 编码的三大顽疾`

### 何时用
- 有清晰的"问题→解决"叙事
- 痛点是读者高度共鸣的

---

## 模式 3:权威背书型

**适用:** 大厂、知名团队、知名个人出品

### 公式
```
{机构/作者背书}!{主体}:{核心价值}
```

### 实例
- `腾讯开源!WeKnora:企业级 RAG 知识库`
- `阿里开源!Pixelle-Video:AI 全自动短视频引擎`
- `Datawhale 出品!《Hello-Agents》:智能体学习教程`
- `OpenAI 突然官宣:这件事可能改变所有人的工作方式`

### 何时用
- 背书 > 项目本身的传播力
- 知名机构/人物站台

---

## 模式 4:数字归类型

**适用:** "X 个"特征明显的内容(教程合集、工具数、版本数)

### 公式
```
{数字}+{特征}!{主体}:{说明}
```

### 实例
- `147 位 AI 专家、12 大部门!agency-agents:一人即拥有完整代理公司`
- `5 个被忽视的副业,正在悄悄改变 90 后的命运`
- `7 张图,讲清楚 GPT-5 的所有秘密`

### 何时用
- 内容本身就是"集合"
- 数字本身就是亮点

---

## 模式 5:身份共鸣型

**适用:** 针对某类特定用户群体

### 公式
```
{目标群体}的{XX}!{主体}:{满足该群体的需求}
```

### 实例
- `给研究生打造的"半自动化科研助手"`
- `Java 程序员都在用的:8.1k Star 若依 RuoYi`
- `30 岁还在迷茫?这套方法论让你少走 5 年弯路`

### 何时用
- 目标用户清晰
- 想精准触达特定人群

---

## 模式 6:历史/时空型

**适用:** 教程类、历史性总结、长期项目

### 公式
```
从 {起点}到 {终点}:{主体}{说明}
```

### 实例
- `从 1948 年到 2020 年:一份贯穿 70 多年 AI 发展史的论文清单`
- `从程序员到独立创业者:这 8 年我踩过的坑`

### 何时用
- 项目有时间跨度
- 教程类资源合集

---

## 模式 7:反差悬念型

**适用:** 项目/事件看起来"不可能"或"反直觉"

### 公式
```
{看似不可能的承诺}!{主体}{说明}
```

### 实例
- `让 Claude Code 变成"手机 App":Happy 的端到端加密 + 实时语音`
- `12.4k Star！一条命令克隆任意网站`
- `一夜重写 Claude Code:史上最快破 10 万 Star 的项目诞生记`

### 何时用
- 项目/事件有"魔法时刻"
- 第一眼反应应该是"这真的能做到吗?"

---

## 模式 8:疑问钩子型

**适用:** 引发好奇 / 直接抛出读者关心的问题

### 公式
```
{反直觉问题}?{暗示答案存在}
```

### 实例
- `为什么聪明人都在悄悄囤这只股票?`
- `LLM 真的会推理吗?这篇论文给出了出乎意料的答案`
- `用了 3 个月 Cursor,我决定换回 VS Code,这是为什么`

### 何时用
- 内容是观点/思考
- 读者可能本来就在思考这个问题
- 需要"打开率优先"的标题

---

## 模式 9:福利紧迫型

**适用:** 免费/限时/福利类内容

### 公式
```
{送什么}+{紧迫感}+{对受益者的暗示}
```

### 实例
- `老黄请客!英伟达免费 1 年 API Key:80+ 顶级模型不限 Token`
- `限时 7 天!某大厂送出价值 5000 的 AI 工具年卡`
- `白嫖警告!这个免费工具可能下周就要收费了`

### 何时用
- 真实的免费/福利
- 时间敏感(过期就没了)
- ⚠️ 不要乱用紧迫感,**只在真有时间限制**时用

---

## 模式 10:故事型

**适用:** 戏剧性事件、人物故事

### 公式
```
{戏剧化的事件描述,带有悬念}
```

### 实例
- `一个失眠的凌晨,他用一夜重写了 Claude Code`
- `25 岁,被 7 家公司拒绝,如今做出 50k Star 项目`
- `这条推文,让 OpenAI CEO 半夜删了发布会`

### 何时用
- 内容本身有强戏剧性
- 想用故事吸引非技术读者

---

## 模式 11:观点宣言型

**适用:** 强观点文章

### 公式
```
{反共识/强主张的观点}
```

### 实例
- `Cursor 已死,Claude Code 才是 AI 编程的未来`
- `2026 年还在卷训练?推理才是真正的金矿`
- `不要再学 AI 了,你应该学的是这个`

### 何时用
- 文章是观点型,你有清晰立场
- 想引发讨论(观点越鲜明转发越多)
- ⚠️ 慎用,要确保你的观点能在文章里站住脚

---

## 标题质量检查表

写完标题后自检:

- [ ] 长度 25-45 字
- [ ] 包含具体数据/特征
- [ ] 包含主体英文名(便于搜索)
- [ ] 包含核心价值/差异化点
- [ ] 中文标点(用!不是!)
- [ ] 不是营销号腔
- [ ] 看完就知道这文章值不值得点开

---

## 红线(必须避免)

❌ **绝对避免:**
- "震惊!"、"逆天!"
- "碾压"、"屠榜"、"秒杀"
- "一文读懂"、"一文看尽"(套路化严重)
- "封神"、"屠榜"、"逆袭"
- 标题超过 50 字
- 全部大写英文项目名

⚠️ **可用但克制(每 10 篇 1 次):**
- "神作"、"神级"
- "必读"、"必备"、"必看"
- 感叹号(每个标题最多 1 个)

---

## 不知道选哪个模式?

按以下优先级:

1. 内容是**福利/免费** → 模式 9
2. 数据**足够震撼** → 模式 1
3. 有**大厂/名人背书** → 模式 3
4. 解决**明确痛点** → 模式 2
5. 内容是**对比** → 模式 4
6. 内容是**故事** → 模式 10
7. 内容是**观点** → 模式 11 或 8
8. 目标用户**特定** → 模式 5
9. **以上都不明显** → 模式 7(反差悬念型)兜底

---

## 多个模式可以组合

实际写作时,可以**叠加 2 种模式**:

- 模式 1 + 模式 3:`腾讯开源 5.6k Star 项目!WeKnora 让文档秒变智能问答`
- 模式 9 + 模式 1:`老黄请客!英伟达免费 1 年 API Key:80+ 顶级模型不限 Token`
- 模式 4 + 模式 5:`147 位 AI 专家!给一人公司打造的数字代理团队`

组合时**不要超过 50 字**,选最强的两个点即可。
