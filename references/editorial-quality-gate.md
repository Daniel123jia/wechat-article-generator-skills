# Editorial Quality Gate v1.1

交稿前必须通过。

## A. 主线

- [ ] 我能用一句话说出全文核心判断
- [ ] 一级标题都服务于这句话
- [ ] 没有为了“完整”加入无关章节

## B. 信息增量

- [ ] 不只是复述原素材
- [ ] 至少有 2–3 个自己的解释 / 对比 / 边界
- [ ] 每节回答了“为什么重要”

## C. 事实

- [ ] 数据有来源
- [ ] 日期明确
- [ ] benchmark 条件明确
- [ ] 官方自述没有包装成独立证据
- [ ] 推测有标识

## D. 微信阅读体验

- [ ] 30 秒内进入核心
- [ ] 一段 1–3 句
- [ ] 一级标题不超过约 10 个
- [ ] 一级标题 18 px 映射
- [ ] 二级标题 16 px 映射
- [ ] 二级标题没有和一级同级
- [ ] emoji 克制

## E. 推荐规范

- [ ] 标题完整不误导
- [ ] 无无效导流
- [ ] 无低创作度拼接
- [ ] 无不实/过时数据
- [ ] 文章本身独立有价值

## F. 结尾

- [ ] 没有机械“综上所述”
- [ ] 没有鸡汤口号
- [ ] 留下的是观点，不是全文复述
