# 公众号写作研究方法 v1.1

## 1. 原始来源优先

优先级：

```text
论文正文 / 官方文档 / 源码 / 官方公告
>
作者说明 / Release / Issue
>
高质量第三方分析
>
一般博客 / 二手整理
```

## 2. GitHub 项目

至少检查：

- README
- repo description
- License
- 最新 Release
- 最近 commit
- 关键源码（当核心 Claim 依赖实现时）
- Star / Fork（仅在文章需要时）
- README 与源码是否一致

## 3. 论文

至少检查：

- Abstract
- Introduction
- Method / Results 中支撑核心 Claim 的部分
- Conclusion / Limitation
- 发表状态
- 代码 / 数据是否开源

## 4. 新闻

至少两类来源交叉：

- 原始公告
- 可靠报道

## 5. 写文章前先填“判断卡”

```text
素材：
我认为它真正值得写的是：
读者最容易误解的是：
最有分量的 3 个事实：
最重要的 2 个限制：
我能提供的新增判断：
一句话主线：
```

## 6. 信息增量

至少尝试找到 2–3 个：

- README 与源码差异；
- Benchmark 的真实条件；
- 官方表述与媒体标题的差异；
- 为什么这个设计重要；
- 和同类产品本质区别；
- 对科研/产品/工作流的延伸价值；
- 当前限制。

如果完全没有增量：

> 文章宁可短，也不要机械扩写。
