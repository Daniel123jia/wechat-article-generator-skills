# 微信公众号排版与字号规范 v1.1

## 核心原则

> **正文一级标题不要太大。二级标题必须明显小于一级标题。**

## 推荐字号

| 元素 | 建议字号 | 建议字重 |
|---|---:|---:|
| 文章主标题 | 24–28 px | 600–700 |
| 正文一级标题 | **18 px** | 600–700 |
| 正文二级标题 | **16 px** | 600 |
| 正文三级强调 | 15 px | 600 |
| 正文 | 15 px | 400 |
| 注释 / 来源 | 13–14 px | 400 |

## Markdown 映射

```markdown
# 文章标题

## 正文一级标题

### 正文二级标题

#### 少量三级强调
```

### 禁止

- 正文一级标题继续使用 `#`
- 二级标题和一级标题一样大
- 二级标题比一级标题更大
- 一篇文章混用 4–5 种标题视觉体系
- 每两三段就放一个大标题

## 标题节奏

一级标题：

- 一般 6–10 个以内；
- 每个一级标题应承载一个完整判断；
- 标题尽量是“结论句”，而不是“功能 1 / 功能 2”。

二级标题：

- 只在一级标题内部确实需要拆分时使用；
- 如果一个一级标题下面只有 1 个二级标题，通常不需要二级标题。

## 正文

- 15 px；
- 1–3 句话一段；
- 行距建议 1.7–1.85；
- 段间距明显大于行间距；
- 重点可加粗，但每段通常不超过 1 个重点句。

## 提醒

Markdown 文件只能表达“层级”，不能保证微信公众号编辑器最终的像素字号。

如果后续渲染器支持 CSS / HTML，应优先映射为：

```css
.article h2 { font-size: 18px; }
.article h3 { font-size: 16px; }
.article p  { font-size: 15px; line-height: 1.8; }
```
