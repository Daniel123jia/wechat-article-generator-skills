# Mode: 通用兜底(General)

**触发信号:**
- 素材类型不明确
- 不属于其他任何专用模式
- 用户给的是混合素材
- 用户的需求模糊

**推荐结构:** 根据素材性质选 A-I 中最适合的一种

**推荐长度:** 2500-4500 字

---

## 使用建议

### 第一步:再次尝试归类

在用通用模式前,**再次尝试**判断素材类型:

| 如果素材是... | 用专用模式 |
| :--- | :--- |
| GitHub 仓库 | github-project.md |
| 新闻链接 | news-event.md |
| 推特帖子 | twitter-post.md |
| 论文 | research-paper.md |
| 产品 | product-review.md |
| 操作步骤 | tutorial-guide.md |
| 个人观点 | opinion-essay.md |
| 免费福利 | freebie-deal.md |

### 第二步:如果实在归类不了

可能是以下情况:

1. **混合内容** — 一篇文章要同时介绍工具 + 教程 + 评测 → 选最主导的那种,辅以其他模式的元素

2. **创新形态** — 全新的内容类型(比如某种新型 AI 应用) → 灵活组合多种结构

3. **简单分享** — 用户只是想分享一个东西,没有特别强的目的 → 用结构 A(介绍型)

4. **不确定** — 直接询问用户:
   > "我想确认一下,这个素材你希望突出的是它的功能介绍、使用教程、还是个人评测?"

## 通用研究流程

如果是一个不熟悉的素材类型:

### Step 1:理解素材本质

- 这是什么?(物体/事件/想法)
- 为什么用户觉得值得写?
- 读者会从哪个角度感兴趣?

### Step 2:抓所有公开信息

```
web_fetch(用户给的链接,如果有)
web_search("素材关键词")
web_search("素材关键词 中文")
web_search("素材关键词 评论 / 讨论")
```

### Step 3:核实关键事实

不管是什么类型,这些都要验证:
- 主体名称
- 关键日期
- 数据
- 论点

## 灵活的文章结构

### 通用骨架(适用任何素材)

```markdown

> {副标题}

---

## {开篇钩子}

[场景化共鸣开头]

---

```

## 写作要点

### 1. 即使不属于专用模式,核心规则不变

- 真实信息(查证)
- 中文原生(不翻译腔)
- 信息密度(每段都有干货)
- 共鸣开头
- 不鸡汤收尾
- 独立成文

### 2. 灵活组合元素

不必死板套结构。可以:
- 教程类元素 + 介绍类元素
- 观点 + 数据
- 故事 + 反思

只要逻辑顺,读者就买账。

### 3. 不知道怎么开头时

万能开头模板:

**模板 1:场景共鸣**
> "你是不是也遇到过这种情况......"

**模板 2:数据反差**
> "{某个让人意外的数据},这背后是......"

**模板 3:故事钩子**
> "上周,我看到了一件事......"

**模板 4:疑问引入**
> "为什么 XX 突然火了起来?"

### 4. 不知道怎么收尾时

万能收尾模板:

**模板 1:数据收束**
> "{数据/事实},这份成绩值得每一个 {群体} 关注。"

**模板 2:行业反思**
> "在一个 X 的时代,XX 代表了一种 Y 的态度。"

**模板 3:开放式收束**
> "至于 XX 会走向何方,让我们拭目以待。"

## 不确定时,询问用户

通用模式的优势是**灵活**,但也容易写成"四不像"。

如果实在拿不准方向,**询问用户**:

```
我看到你提到的 {素材}。在写之前,我想确认一下:

1. 你希望这篇文章的主要目的是什么?
   A) 介绍这个东西是什么(类似产品介绍)
   B) 教读者怎么用(类似教程)
   C) 分享个人体验/评价
   D) 表达对这个东西的观点
   E) 其他

2. 目标读者是谁?(技术圈 / 大众 / 特定专业人士 / ...)

3. 有没有偏好的角度或要重点突出的内容?
```

**澄清后再开始写**,比写错了重写更有效率。

## 已知陷阱

### 陷阱 1:用通用模式逃避思考

通用模式不应该是"我懒得归类就用这个"。
**先认真尝试归类**,实在不行才用通用。

### 陷阱 2:写成大杂烩

通用模式 ≠ 什么都写一点。
要有**主导线索**——读者读完知道你想说什么。

### 陷阱 3:节奏失控

通用模式因为没有固定结构,容易写成长短不一、节奏怪异的文章。
- 严格按 2500-4500 字
- 段落控制
- 信息密度

### 陷阱 4:忘了基本元素

哪怕用通用模式,以下元素**永远不能少**:
- 抓眼球的标题
- 副标题引述
- 共鸣开头
- 信息表格
- 互动话题
- CTA

## 当用户素材完全无法处理时

如果你尝试了搜索,发现:
- 信息不存在
- 信息明显是假的
- 内容涉及违法/敏感

**坦诚告诉用户**:

```
我尝试搜索了你提供的素材,但发现以下问题:
- 问题 1
- 问题 2

可能的原因:
- ...

建议:
- 提供更多信息(链接/上下文)
- 换一个更明确的素材
- 等等再写(等信息更充分)
```

不要硬着头皮写假内容。
