# Mode: 学术论文解读

**触发信号:**
- arxiv.org 链接
- DOI 链接
- 用户提到"这篇论文"、"paper"、"研究"
- 标题看起来像学术论文(有冒号、有复杂术语)
- 用户给出 PDF

**推荐结构:** D(解读型)

**推荐长度:** 3500-5000 中文字符(论文内容多,可适当超长)

---

## 研究流程

### Step 1:抓论文页面(必做)

```
web_fetch("https://arxiv.org/abs/XXXX.XXXXX")
```

提取:
- 论文标题(英文)
- 作者列表 + 所属机构
- 发表日期
- Abstract(摘要)
- 相关链接(项目页、代码、demo)

### Step 2:看 PDF 内容(如果需要深度解读)

如果 abstract 不够,要 fetch PDF:
```
web_fetch("https://arxiv.org/pdf/XXXX.XXXXX")
```

或者搜索论文的解读:
```
web_search("论文标题 解读")
web_search("论文标题 review summary")
```

### Step 3:核实关键信息

- 作者是否真有其人?(避免被仿冒)
- 机构是否真实?
- 是否已经被同行评议?(arXiv 上很多预印本)
- 是否有后续工作 / 被反驳?

```
web_search("第一作者 机构 论文")
web_search("论文标题 critique limitation")
```

### Step 4:找中文解读(可选)

很多中文 AI 公众号 / 知乎专栏会解读热门论文。
看看别人的解读视角,**但不要照搬**。

```
web_search("论文标题 中文 解读 知乎")
```

[让读者觉得"这个问题很重要"或"这个结论很意外"]

## 写作要点

### 1. 不要堆砌术语

读者可能不是该领域专家。
- 第一次出现的术语要解释
- 数学公式能省就省
- 用类比代替复杂推导

### 2. 引用要准确

引用论文中的关键论点时:
- 标明在哪个 section
- 数字要从原文抄(不要凭印象)
- 关键术语保留英文(便于读者去查)

### 3. 区分"论文说"和"我的解读"

- "作者认为..."(论文原意)
- "我个人觉得..."(你的解读)
- "更激进的解读是..."(扩展观点)

不要把自己的解读包装成论文的原意。

### 4. 谨慎对待预印本

arXiv 上的预印本**没有经过同行评议**。
- 要标明"这是预印本"
- 不要把结论说得过于绝对
- 关注后续是否被会议接收

### 5. 论文 ≠ 真理

哪怕是顶会论文,也可能:
- 实验有方法论问题
- 后续工作无法复现
- 在更大数据集上失效

文章中要**保持批判性思维**,不当吹鼓手。

### 6. 标题模式建议

- 反共识结论:**模式 11(观点宣言型)** + 模式 8(疑问钩子型)
- 重磅成果:**模式 1(数据震撼型)**
- 大牌团队:**模式 3(权威背书型)**

## 已知陷阱

### 陷阱 1:把 abstract 当全部

很多人写论文解读只看 abstract。
- abstract 只是摘要,**真正的细节在 body**
- 至少要看 Introduction 和 Conclusion
- 关键 claim 要去 Method 和 Results 验证

### 陷阱 2:忽略论文已被反驳

热门论文经常很快被后续工作挑战 / 反驳。
- 写之前搜一下"论文标题 critique"
- 如果有重要反驳,要在文章中提及

### 陷阱 3:把"在某个 benchmark 上 SOTA"夸大

很多 SOTA 是:
- 只在特定 benchmark
- 只比某些 baseline 好
- 用了大量计算资源

不要把 "SOTA on X benchmark" 说成 "全面超越"。

### 陷阱 4:作者机构造假

用 web_search 核实第一作者真的在那个机构。
- 看作者主页
- 看他们之前的论文
- 避免被假论文骗

### 陷阱 5:复现性问题

论文写得再漂亮,如果**别人复现不出来**,价值会大幅下降。
- 看有没有开源代码
- 看是否有人成功复现
- 如果复现性差,要在文章中提及
