# Mode: 福利/羊毛/免费政策

**触发信号:**
- 用户提到"免费"、"白嫖"、"领取"、"福利"、"羊毛"
- 涉及"限时"、"限量"、"截止"等紧迫词
- 政策类:某公司开放免费 API / 某产品免费开放
- 优惠类:打折、立减、抽奖

**推荐结构:** G(福利羊毛型)

**推荐长度:** 2500-4000 字

---

## 研究流程

### Step 1:核实政策真实性(关键!!)

**福利类内容最容易被假消息坑**。要在第一时间核实:

```
web_fetch(官方公告链接)
web_search("福利关键词 官方")
```

至少要确认:
- 这是**官方政策**还是民间传言?
- 政策**目前还有效**吗?
- 是否有限制条件?

### Step 2:核实关键参数(必做)

福利类内容最重要的就是参数:

| 参数 | 必须明确 |
| :--- | :--- |
| 谁送 | {公司/平台名} |
| 送什么 | {具体内容} |
| 多少 | {数量/额度} |
| 期限 | {生效到何时} |
| 谁能领 | {适用人群} |
| 怎么领 | {操作步骤} |
| 限制 | {什么不能做} |

### Step 3:研究领取流程(必做)

亲自走一遍流程(或找走过的教程),确认:
- 注册步骤
- 验证步骤(手机/邮箱)
- 关键卡点(在哪一步容易卡)
- 领取后的使用方式

```
web_search("福利名 申请教程")
web_search("福利名 怎么领取")
web_search("福利名 踩坑")
```

### Step 4:核实"是否真的免费"

很多"免费"福利有暗藏陷阱:
- 信用卡押金
- 试用期后自动扣费
- 要绑定支付方式
- 数据被用于训练

**要在文章中如实揭示**,不能只讲好不讲坏。

## 写作要点

### 1. 真实性是底线

福利类文章最容易翻车。
- 政策已结束 → 读者按教程做白费力气
- 没说有付费陷阱 → 读者被扣钱来骂你
- 编造价值 → 公信力归零

**写之前一定核实!**

### 2. 紧迫感要诚实

如果福利真的"限时",可以强调时间紧迫:
- "限时 7 天"(确实是 7 天)
- "目前还有效,但可能随时调整"

但不要**编造紧迫感**:
- ❌ "可能下周就要收费了"(没有依据)
- ❌ "马上就要结束"(实际还有半年)

虚假紧迫感是网络营销最低劣的手段。

### 3. 必须揭示风险

哪怕福利再好,也要写明潜在风险:
- 是否需要绑卡 / 自动续费
- 是否会用你的数据
- 是否有隐藏限制
- 国内用户是否真的能用

把读者当成年人,不要"先骗他领,反正不是我的事"。

### 4. 步骤要够具体

新手按教程做,**每一步**都要能跟上:
- 哪个按钮在哪
- 验证码怎么收
- 失败了怎么办

### 5. 提供"如果失败"的兜底

教程不可能 100% 适用所有人。
- 主流程不通时的备用方案
- 中国用户的特殊处理(VPN / 国内手机号等)
- 客服联系方式

### 6. 标题模式建议

- 福利紧迫:**模式 9(福利紧迫型)**
- 大公司送福利:**模式 3(权威背书型)** + 模式 9
- 数据震撼:**模式 1(数据震撼型)**

例子:
- `老黄请客!英伟达免费 1 年 API Key:80+ 顶级模型不限 Token`
- `阿里送福利!通义千问 API 限时白嫖 100 万 Token`

## 已知陷阱

### 陷阱 1:政策已结束你还在写

福利政策变化快。**写之前一定确认还有效**。
- 看官方页面是否还显示申请入口
- 看最近用户的反馈
- 如果不确定,在文中标注"截至 X 月 X 日有效,以官方为准"

### 陷阱 2:把"试用"当"免费"

很多"免费"实际是试用:
- 30 天后扣费
- 用完一定额度自动扣费
- 取消订阅有套路

**严格区分**:
- 真正免费 → "完全免费,无需信用卡"
- 试用 → "试用 30 天,到期自动续费 $X/月"

### 陷阱 3:把测试版当稳定版

很多免费政策来自:
- 灰度测试
- 公测期
- 推广期

这些政策**随时可能调整**。文章中要提醒。

### 陷阱 4:国内用户用不了你没说

很多福利只对**美区/欧区**用户开放:
- 需要海外信用卡
- 需要海外手机号
- 需要 VPN

中文公众号读者大多是国内用户。**国内能不能用必须明确**。

### 陷阱 5:推荐的工具自己有毒

有些"福利"是三方工具,可能:
- 转卖你的数据
- 偷你的 API Key
- 是钓鱼网站

**不要推荐你不了解的"中转工具"**。只推荐官方福利或久经考验的工具。

### 陷阱 6:被当成"羊毛党"账号

公众号如果天天发"白嫖""领取"这种内容:
- 平台可能限流
- 读者会觉得低质
- 会被主流圈层鄙视

福利类文章可以写,但要**保持品味**:
- 不要标题党到极致
- 不要全文都是"快领快领"
- 要有干货分析,不只是搬运
