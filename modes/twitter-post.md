# Mode: 推特/X 帖子展开

**触发信号:**
- URL 含 x.com / twitter.com / nitter.net
- 用户提到"这条推文"、"X 上看到"、"Twitter 帖子"
- 用户粘贴一段话并说是某人的推文
- 用户给截图(用 vision 看图)

**推荐结构:** F(推特帖子展开型)

**推荐长度:** 2000-3500 中文字符

---

## 研究流程

### Step 1:获取原帖内容

**方式 A:用户给链接**
```
web_fetch("https://x.com/user/status/123456")
```

注意:X/Twitter 现在反爬严格,**web_fetch 经常拿不到完整内容**。

**方式 B:用户给截图**
直接看图片识别。

**方式 C:web_fetch 失败时**
搜索原帖的关键短语:
```
web_search("帖子的独特句子片段")
```

通常会找到引用该帖的中文报道、知乎讨论、Reddit 截图。

---

### Step 2:核实作者身份(必做)

**绝对不能** 把假账号当真账号写。

```
web_search("用户名 真实身份 公司 职位")
web_search("@username Twitter who is")
```

确认:
- 真实姓名
- 当前职位
- 之前的成就(为什么他的话有分量)
- 蓝勾认证(虽然现在不太可靠)

### Step 3:理解帖子的真正含义

推特帖子 280 字,经常有大量隐含语境:
- 业内梗 / 黑话
- 之前发生的事(才能理解这条帖子在回应什么)
- 圈内争议

**通过搜索还原上下文:**
```
web_search("帖子主题 背景 行业")
web_search("帖子涉及的产品/公司 最近动态")
```

### Step 4:看引发的讨论

```
web_search("帖子作者 + 关键词 + 反应")
web_search("帖子主题 评论 讨论")
```

挑 3-5 条有信息量的回复(支持/反对/扩展)。

## 写作要点

### 1. 引用必须准确

推特帖子的力量在于**作者的原话**。
- 不要改写原话
- 不要编造作者没说过的话
- 翻译要忠于原文,重要的词保留英文

### 2. 作者身份可信度是核心

为什么读者要看一个推文?**因为是 X 说的**。
- 没有作者背景介绍 = 帖子失去了一半价值
- 作者背景要写清楚:头衔、成就、为什么是 authority

### 3. 还原上下文很重要

X 平台的内容常常依赖大量"圈内语境"。
- 不解释清楚,读者会一头雾水
- 解释清楚,读者会觉得"啊,原来如此!"

### 4. 评论区是宝藏

X 的精华常常在评论区。
- 挑 3-5 条不同立场的优质回复
- 评论选材体现你的判断力

### 5. 不要二手信息当一手

如果是从中文媒体转的转的转的——尝试找原始推文。
**层层转述会失真**。

### 6. 标题模式建议

- 知名作者发帖:**模式 3(权威背书型)** + 模式 11(观点宣言型)
- 戏剧性帖子:**模式 10(故事型)**
- 反直觉观点:**模式 8(疑问钩子型)**

## 特别注意:推特特定的雷区

### 雷区 1:把 fake account 当真号

X 上有大量仿冒账号(Sam Altman 的仿冒账号一抓一大把)。
**核实账号真实性**:
- 看注册时间
- 看历史发言
- 看主流媒体是否引用过这个账号

### 雷区 2:把删除的帖子当存在

X 帖子可以快速删除。如果你要写的帖子已经被删了:
- 尝试找网页归档(archive.org / Wayback Machine)
- 找截图或转载
- 实在找不到就放弃这个素材

### 雷区 3:断章取义

一段长 thread 中的某句话,脱离上下文意思可能完全不同。
**完整 thread 都要看**,不能只看高赞片段。

### 雷区 4:把私人吐槽放大

有些帖子是作者随手的私人吐槽,**不代表正式立场**。
- 不要把这种内容写成"X 公开表态"
- 文章中可以注明"在私人推文中..."

### 雷区 5:涉及具体人物的批评

如果作者在帖子里点名批评了某个具体人/公司——
- 不要为了博眼球放大这种攻击
- 描述事实,不参与人身攻击
- 给被批评方留出表达空间(也提到他们的回应)

### 雷区 6:政治/争议话题

X 上很多帖子涉及政治、地缘等敏感话题。
- 公众号写这类内容**风险极高**
- 建议**避开**或**只描述事实不站队**

## 当原帖很短时怎么写?

很多爆款推文只有一两句话。怎么撑起一篇 2000-3500 字的文章?

**1. 横向铺开**
- 这句话谁说的(作者背景)
- 为什么这话现在说(时机)
- 这话以前有人说过吗(历史脉络)
- 这话引发了什么(影响)

**2. 纵向挖深**
- 字面意思
- 引申含义
- 行业暗示
- 对你意味着什么

**3. 加入自己的判断**
- 我同意他吗?
- 我会怎么解读?
- 我会怎么应用?

短帖子展开成长文,**作者的解读能力**是核心。
