# Mode: 观点/思考文

**触发信号:**
- 用户提到"聊聊 XX"、"我对 XX 的看法"、"对 XX 的思考"
- 用户分享自己的观点/经历,希望写成长文
- 文章是"立场型"而非"信息型"

**推荐结构:** C(观点型)

**推荐长度:** 2500-4000 字

---

## 研究流程

观点型文章的"研究"和其他类型不同。这里要研究的是:

### Step 1:理解用户的核心观点

**第一件事:用户的核心立场是什么?**

如果用户描述模糊,**问清楚**:
- 你想表达的核心观点是什么?(一句话能说完吗)
- 你反对的是什么?
- 你认为的对立观点是什么?

### Step 2:找事实支撑

观点 ≠ 主观臆断。强观点必须有事实支撑。

```
web_search("观点关键词 数据 事实")
web_search("观点关键词 案例")
web_search("行业 现状 数据")
```

至少为每个论点找 1-2 个具体事实/案例/数据。

### Step 3:看反方观点

强观点要预判反方。
- 持相反观点的人会怎么反驳?
- 他们的理由有道理吗?
- 你怎么回应他们的反驳?

```
web_search("观点关键词 反对")
web_search("观点关键词 不同看法")
```

### Step 4:作者背景(可选)

如果用户是知名人物 / 行业从业者,提及背景会增加可信度:
- 他在这个领域多久了?
- 他做过什么?
- 他凭什么有发言权?

## 文章结构(C 观点型)

```markdown
# {标题:观点本身 / 反直觉判断}

> {副标题:观点的精华句}

---

## {引子}

[一个具体场景或现象作为切入]

不要直接抛观点,而是用一个**让读者觉得"诶,这是我的事"** 的场景。

例如:
- "上周和一个朋友聊天,他说他放弃了 Cursor,改回 VS Code 了。"
- "前两天看到一组数据,让我突然想清楚一件事。"

---

## 我想说的核心观点

[直接、清晰地抛出观点,一两句话能说完]

> **{核心观点的精华句}**

---

## 论证 1:{支撑论点 1}

[展开论证]

**事实:** {具体数据 / 案例 / 引用}
**为什么这说明 X:** [推理]

---

## 论证 2:{支撑论点 2}

[同上]

---

## 论证 3:{支撑论点 3}

[同上]

[通常 3-5 个论证,每个 200-400 字]

---

## 反方观点的预判

[承认对立观点的合理性]

**有人会说:** {反方典型论点}

这种说法**不是没道理**,确实......

---

## 但我仍然坚持

[为什么你的观点更站得住脚]

- 反驳点 1:...
- 反驳点 2:...
- 关键差异:...

---

## 这对你意味着什么

[把观点落地到读者的实际行动]

- 如果你是 X,你应该...
- 如果你是 Y,你可以...
- 如果你是 Z,值得思考...

---

## 写在最后

[开放式收束 / 留给读者思考]

---

> **互动话题**:你认同我这个观点吗?或者你有不同的看法?欢迎在评论区争论 👊

**觉得有启发,点「赞」+「在看」,转发给可能不认同你观点的朋友,看看他们怎么说!** 🙏
```

## 写作要点

### 1. 观点要鲜明

观点文最忌**和稀泥**。
- "我觉得 X 有好有坏" → 这不是观点,是废话
- "我觉得 X 是错的,因为..." → 这才是观点

文章要敢于**站队**。

### 2. 但要有事实支撑

光有观点没有支撑 = 鸡汤 / 情绪宣泄。
- 每个论点都要有数据/案例/引用
- 不能纯靠"我感觉"
- 不能用"很多人认为"代替真正的来源

### 3. 承认反方合理性

强观点的标志:**承认对方有道理,但你仍然不同意**。
- "反对者说 X,这并非没有道理。但..."
- 不要把对手描述成笨蛋
- 不要把自己描述成全知

### 4. 对事不对人

可以批评观点、行为、决策。
**不要批评人格、能力、人品**。
- ✅ "Cursor 的产品决策走错了方向"
- ❌ "Cursor 的 CEO 太蠢了"

### 5. 用词克制

强观点 ≠ 极端用词。
- 用"我认为""我觉得""值得思考"——而不是"绝对""一定""必须"
- 给读者留思考空间

### 6. 标题模式建议

- 强主张:**模式 11(观点宣言型)**
- 反共识:**模式 8(疑问钩子型)**
- 比较型:**模式 2(对比落差型)**

## 已知陷阱

### 陷阱 1:把抱怨当观点

"XX 真垃圾"——这不是观点,这是抱怨。
观点应该有:
- 清晰的立场
- 支撑的论据
- 对读者的价值

### 陷阱 2:观点漂移

文章前面说 X,后面说 Y,中间又跑到 Z。
**整篇文章要围绕 1 个核心观点**。

### 陷阱 3:论证靠"听说"

"听说 XX 公司不行了" → 没用。
论证要靠:
- 公开数据
- 具体案例
- 可验证的事实

### 陷阱 4:政治/敏感话题

涉及国家、宗教、地缘、特定政治人物的观点文 → **建议绕开**。
公众号上发表政治观点风险极高。

### 陷阱 5:对个人发动攻击

哪怕你强烈不同意某个公众人物的言行:
- 不要用侮辱性语言
- 不要扣帽子
- 描述事实,让读者自己判断

### 陷阱 6:把鸡汤当观点

"我们都应该相信自己" → 这不是观点,这是空话。

真正的观点应该:
- 有反驳对象(不同意什么)
- 有支撑(为什么这么认为)
- 有 take-away(读者能拿走什么)

## 观点文的高质量标志

判断你的观点文是否合格:

- [ ] 一句话能说出核心观点吗?
- [ ] 这个观点会不会引发不同意见?(不引发分歧的观点不算观点)
- [ ] 至少 3 个具体事实支撑?
- [ ] 主动承认反方合理性?
- [ ] 给读者了具体的 take-away?
- [ ] 没有人身攻击?
- [ ] 没有政治雷区?

如果都通过,这是一篇合格的观点文。
